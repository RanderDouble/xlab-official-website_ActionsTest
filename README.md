## 🚀 快速开始

### 1. 环境准备
确保你的电脑已安装 [Node.js](https://nodejs.org/) (建议版本 v18.17 或更高)。

### 2. 安装依赖
在项目根目录下打开终端，运行以下命令：
```bash
npm install
```

### 3. 启动开发服务器
运行以下命令启动本地预览：
```bash
npm run dev
```
启动后，在浏览器访问 [http://localhost:3000](http://localhost:3000) 即可查看效果。

## 📂 目录协作规范

为了减少 Git 冲突，请遵守以下组件存放规则：

- `src/app/`：定义页面路由。尽量保持 `page.tsx` 简洁，只引用 components。
- `src/components/common/`：存放全局通用的 **Header.tsx** 和 **Footer.tsx**。
- `src/components/sections/`：**协作核心区**。按页面建立文件夹（如 `/home`, `/about`），将页面的大块区块拆分为独立组件。
- `src/lib/data.ts`：所有页面展示用的文字、图片链接、Mock 数据统一定义在这里，不要硬编码在组件里。
- `public/`：存放 logo、图标、占位图。
